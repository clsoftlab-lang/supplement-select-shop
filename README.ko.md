# 메딕스 Medix — 맞춤 영양제 셀렉트샵 (데모)

**English: [README.md](./README.md)**

고객별로 영양제를 추천해 주는 **큐레이션 셀렉트샵** SPA입니다. 빌드 도구 없이 순수
**HTML + CSS + ES 모듈 JavaScript**로 만들어졌고, 브라우저에서 **데모 모드**로 완전히
동작하며 GitHub Pages로 배포됩니다.

**🔗 라이브 데모: https://clsoftlab-lang.github.io/supplement-select-shop/**

## 무엇인가요

메딕스는 카탈로그를 둘러보고, 짧은 설문으로 **맞춤 조합**을 추천받고, 장바구니의
**성분 중복·과다·상호작용을 실시간으로 점검**해 줍니다. 모든 판단은 투명하고 설명
가능한 규칙에 기반합니다.

## 기능

- **카탈로그** — 목적(면역·피로·수면·관절·눈·장건강)·브랜드·가격 필터, 제품/브랜드/성분
  검색, 추천/가격/평점 정렬.
- **제품 상세** — 성분·함량과 **일일 권장량 대비 게이지**, 복용법, 주의사항, 리뷰.
- **맞춤 추천 설문** — 나이·성별·목적·현재 복용 중 → **추천 조합 + 각 추천의 이유**.
- **성분 중복/상호작용 체커** — 장바구니 성분을 실시간 분석해 중복·상한 초과·상호작용 경고.
- **정기구독(모의)** — 15% 할인 토글.
- **장바구니 + 모의결제** — 수량·합계·모의 주문 완료.
- **찜**, **내 영양 루틴** — 아침/점심/저녁 복용 스케줄.
- **부가기능** — 권장량 게이지, **예산 맞춤 추천**, **큰 글씨** 옵션, 다크/라이트, 데모 초기화.

## 추천 엔진 원리 (`js/recommender.js`)

각 제품을 설문 기준으로 점수화한 뒤, 그리디 방식으로 균형 잡힌 조합을 구성합니다.

| 규칙 | 효과 |
|------|------|
| 목적 일치 | 겹치는 목적 1개당 **+30** |
| 연령 보정 | 50세+ → 관절/눈 **+12**, 30세 미만 → 피로 **+6** |
| 성별 보정 | 여성 + 피로 목적 + 철분 함유 → **+8** |
| 예산 | 월예산 초과 **−20**, 예산 내 저렴 **+4** |
| 중복 회피 | 이미 복용 중인 성분 포함 → **−25** |
| 평점 | `rating × 0.8` (동점 정렬) |

`recommend()`는 점수순 정렬 후 **선택한 목적을 하나씩 최고 제품으로 커버**하고 남는
자리를 점수순으로 채웁니다. 그래서 조합이 목적을 고르게 아우르고, 각 추천에는 근거가
함께 표시됩니다.

## 상호작용 체커 원리 (`js/interactions.js`)

장바구니 성분을 **일일 합산량**(`함량 × 하루 섭취횟수`)으로 모은 뒤 `data/nutrients.json`
기준으로 3가지를 점검합니다.

1. **중복** — **2개 이상 제품**에 같은 성분이 있으면 표시.
2. **과다** — 일일 합산 **> 상한(UL)** → **경고**, UL이 없고 **권장량(RDA)의 3배** 초과 → **주의**.
3. **성분 쌍 상호작용** — 사전 정의 쌍(예: 칼슘+철분 흡수, 멜라토닌+GABA 진정)이 함께
   담기면 문서화된 경고 표시.

## 🤖 AI 기능 (API 연동)

메딕스에는 **선택적·플러그러블 AI 레이어**가 포함되어 있으며 3가지 기능을 제공합니다.

1. **AI 영양 상담 챗봇** (`#/ai`) — 건강 목적을 자연어로 물으면 카탈로그 데이터에 근거한
   접근 방식을 안내합니다. **의학적 조언이 아니며, 전문가와 상담하세요.**
2. **설문 → 맞춤 스택 설명** — 추천 엔진이 고른 조합을 친근한 자연어 설명으로 풀어 줍니다
   (추천 결과 → “🤖 AI 맞춤 설명”).
3. **성분 상호작용 자연어 경고** — 장바구니의 중복·과다·상호작용 경고를 쉬운 한국어와
   현실적인 주의사항으로 설명합니다 (장바구니 → “🤖 AI 경고 설명”).

**라이브 데모는 내장 Mock으로 바로 동작합니다**(`ai/config.js`의 `AI_ENDPOINT = ""`).
Mock은 오프라인·결정론적이며 **실제 `recommender.js` / `interactions.js` 엔진을 재사용**하므로
답변이 앱의 데이터에 근거합니다.

### 실제 Claude 연동 (운영자)

[`server/`](./server/README.md)의 **참조용 프록시**를 운영자 서버에 배포하고 사이트가 그
주소를 바라보게 합니다. 브라우저는 `{task, payload}`만 보내고, 프록시가 **서버 측 키**로
Claude를 호출한 뒤 텍스트를 스트리밍으로 되돌려줍니다.

```bash
cd server && npm install
cp .env.example .env          # .env 에 키 입력 (커밋 금지)
ANTHROPIC_API_KEY=... npm start
```

```js
// ai/config.js — 배포한 프록시 주소 지정 (빈 문자열이면 내장 Mock)
export const AI_ENDPOINT = "https://your-proxy.example.com/api/ai";
```

프록시는 `@anthropic-ai/sdk`, 모델 **`claude-opus-5`**, adaptive thinking, 스트리밍을
사용합니다(`server/index.mjs`).

> **🔒 키는 서버 측에만 둡니다.** API 키는 프록시의 `ANTHROPIC_API_KEY` 환경변수에만
> 존재하며, 브라우저·정적 번들·URL·리포지토리에는 절대 두지 않습니다. `check.mjs`가 키
> 커밋 여부를 검사합니다. 이 리포지토리/CI 안에서는 프록시를 실행하지 마세요(CI는
> `node --check` 문법 검사만 하며 API 호출은 없습니다).

## 로컬 실행

빌드 필요 없음. ES 모듈은 `file://`이 아니라 `http://`가 필요합니다.

```bash
python -m http.server 8995
# http://localhost:8995 열기
```

## 검증 / 테스트

```bash
node check.mjs
```

`check.mjs`(CI 사용)는 모든 JSON 파싱, 전체 JS `node --check`(`ai/`·`server/` 포함),
`index.html` 필수 컨테이너, **두 엔진 단위 테스트**(설문→기대 추천, 성분 중복→경고 발생),
그리고 **AI-KIT 검증**(`AI_ENDPOINT` 기본 빈 값, **키 미커밋**)을 수행합니다.
CI: `.github/workflows/ci.yml`.

## 🔒 데모 모드 경계 (중요)

- **허구 제품 + 규칙 기반 조언 — 의학적 조언이 아닙니다. 전문가와 상담하세요.**
- **모의 결제/구독 — 실제 결제·주문·배송이 없습니다.**
- **localStorage는 실제 DB가 아닙니다** — 데이터는 브라우저에만 저장되고 초기화 가능합니다.
- **계정/개인정보(PII) 수집 없음.**
- **실제 제품은** 라이선스된 실제 카탈로그, 전문가(의사·약사) 검수, 실결제, 계정, 서버 DB가
  추가되어야 합니다.

## 기술

프레임워크·번들러 없는 순수 **HTML + CSS + ES 모듈 JS**, 상대경로만 사용. 반응형
모바일 우선, 라이트/다크, 인라인 SVG 제품 이미지. GitHub Pages 그대로 배포 가능.

## 구조

```
index.html            # SPA 셸(필수 컨테이너 + 고지)
css/styles.css        # 테마 토큰, 반응형, 라이트/다크
js/app.js             # SPA: 라우팅·카탈로그·상세·설문·장바구니·루틴
js/recommender.js     # 추천 엔진(점수화·설명 가능)
js/interactions.js    # 중복/과다/상호작용 엔진
js/storage.js         # localStorage 래퍼(try/catch + 초기화)
ai/config.js          # AI_ENDPOINT 스위치("" 이면 내장 Mock)
ai/ai.js              # askAI(task,payload) — Mock ↔ 실제 프록시, task id
server/               # 참조용 Claude 프록시(운영자가 키로 배포)
data/supplements.json # 허구 영양제 38종(성분 + 일일량)
data/nutrients.json   # 영양성분 참조표(RDA/UL) — 게이지·점검용
check.mjs             # CI 검증 + 엔진 단위 테스트 + AI-KIT 검증
.github/workflows/ci.yml
```
